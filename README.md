# 🧠 Deepfake Image Detection

This project aims to detect **deepfake images** using **Convolutional Neural Networks (CNN)**. Deepfakes are AI-generated synthetic media that can be used maliciously to spread misinformation or impersonate individuals. This tool helps classify whether an input image is **real** or **fake**.

## 🚀 Features

- Image Upload & Classification
- Real vs Fake Prediction using CNN
- Trained on custom dataset of real and fake images
- Model evaluation metrics: Accuracy, Precision, Recall, F1 Score
- Web interface using Flask (optional)
